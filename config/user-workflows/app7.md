# App7 phone user

Follow `default.md` in this directory. The app7 developer source is distinct from the app7 Maestro automation project. Find a published APK, or optionally build an APK from a fresh source checkout. Select the exact USB phone or emulator serial with `adb devices -l` before installation. Open a fresh copy of the Maestro automation project in the `ui` window, inspect its runner and device target, then execute the UI flows with the owner. Record source SHA, APK hash, device serial, and flow results.

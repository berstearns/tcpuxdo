# App7 phone user

Follow `default.md` in this directory. Download the newest APK from `hetzner:apps/app7/release/` to the laptop, install and launch it on the sole connected USB phone by default, or specify an emulator serial. Use `AUTO-download-install-and-launch-user-apk.sh app7` for that path. A source build from the fresh checkout is optional; pass its APK path to the same installer. The separate `ui` window opens `app7-maestro-automation`, whose runner is `./run.sh flows/NAME.yaml [data/FILE.tsv]`. Record the remote APK path, downloaded APK hash, device serial, selected flow, and UI result.

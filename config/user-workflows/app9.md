# App9 phone user

Follow `default.md` in this directory. Download the newest APK from `hetzner:apps/app9/release/` to the laptop, install and launch it on the sole connected USB phone by default, or specify an emulator serial. Use `AUTO-download-install-and-launch-user-apk.sh app9`. A source build from the fresh checkout is optional. The `ui` window currently has no verified app9 automation runner; report that gap and record any manual UI result without calling it automated. Record the remote APK path, downloaded APK hash, device serial, and observed app behavior.

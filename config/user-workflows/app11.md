# App11 phone user

Follow `default.md` in this directory. Download the newest APK from `hetzner:apps/app11/release/` to the laptop, install and launch it on the sole connected USB phone by default, or specify an emulator serial. Use `AUTO-download-install-and-launch-user-apk.sh app11`. The twin's developer repo is a Rust domain fence checkout; an optional APK build needs the separate Android repo. The `ui` tmux window opens its `androidApp/maestro/run-all.sh` runner. Record the remote APK path, downloaded APK hash, package/foreground activity, device serial, and UI flow results.

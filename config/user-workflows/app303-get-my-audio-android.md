# App303 phone user

Follow `default.md` in this directory. The app is in `auto-app/` in the fresh monorepo checkout. First look for a published APK and use it if available. Otherwise, optionally build with `auto-app/scripts/AUTO-android-build.sh`. List `adb devices -l`, have the owner choose the USB phone or emulator serial, and use `auto-app/scripts/AUTO-android-install-launch.sh` with that serial and the chosen APK. Keep the source SHA and APK identity together. The `ui` tmux window is for `auto-app/scripts/AUTO-maestro-run.sh` and inspection of `auto-app/mono/android/e2e/USE-CASES.md`; run it only on the chosen device. Report screenshots, flow results, and any first-run issues.

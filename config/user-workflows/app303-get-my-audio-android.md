# App303 phone user

Follow `default.md` in this directory. The fresh checkout is of the nested `auto-app` repository itself. Download the newest APK from `hetzner:apps/app303/release/` to the laptop, install and launch it on the sole connected USB phone by default, or specify an emulator serial. Use `AUTO-download-install-and-launch-user-apk.sh app303-get-my-audio-android`. If the Hetzner directory has no APK, report that missing published artifact; an optional source build is `scripts/AUTO-android-build.sh debug`, followed by installation of that explicit APK path. The `ui` window opens `scripts/AUTO-maestro-run.sh` and `mono/android/e2e/USE-CASES.md`. Record the remote path, APK hash, device serial, screenshots, and flow results.
